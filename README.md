# Montize 0.5.3

An Android finance tracker with a frosted-glass interface.

**Version code:** 14 · **Requires:** Android 9+

[Download APK](./Montize-0.5.3-debug.apk?raw=true)

## Install or update

Download and open the APK on your phone. If prompted, allow installation from your browser or file manager.

For upgrades, install over the existing Montize app and choose **Update**. **Do not uninstall or clear storage: keep your app data.** If an update is rejected, request a compatible APK before removing anything.

## Enable Ryt Bank notifications

Open **Settings → Notification capture**. Enable **Capture payments**, grant **Allow notification access** to Montize in Android settings, then enable **Ryt Bank**. Keep Ryt Bank’s transaction notifications enabled too.

Complete detected transactions save immediately. Tap wallet Activity entries to correct them; incomplete or suspected duplicate notifications stay excluded as **Needs details**.

## Features

- Home and Statistics; multiple wallets and currencies.
- Payment notifications, receipt OCR, manual entry and category learning.
- Budgets, investments/net worth, debts and savings goals.

This debug APK is for private testing; physical-phone/provider coverage remains limited. Capture depends on readable notifications. Balances are tracked, not live bank balances. Fresh receipt rescans can create duplicates.

Records stay on-device; there is no cloud sync or export/restore. Uninstalling or clearing storage removes them. Internet access refreshes public exchange rates.
